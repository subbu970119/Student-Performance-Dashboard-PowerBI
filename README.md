# Student Performance Dashboard (Power BI)

A Power BI report analysing student marks, attendance and pass/fail results.

## Page
**Student Performance Overview** – student count, marks, attendance, pass rate, academic performance trend by year, marks by class, pass vs fail split, with slicers for year, class and department.

## Data Model
Tables: `Student_Data`, `Resource_Summary`.

## Tools
Power BI Desktop, DAX measures, Power Query.
